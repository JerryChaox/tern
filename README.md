# Tern：AI 研究趋势雷达

> 从所有人都能看到的论文里，找出还没被意识到的重要性。

2016 年，Jack Clark 把 arXiv 论文打印出来整理成图表，发现视觉、语音、游戏等领域的能力曲线同时开始指数增长，而且 Nvidia GPU 出现在几乎所有论文里。Tern 把这套方法自动化：

1. **每天抓取**：从 arXiv 拉取 `cs.LG / cs.CL / cs.CV / cs.AI / cs.RO / eess.AS` 的新论文
2. **定期整理成时间线**：每个「信号」（一条作用于标题和摘要的正则）都会变成一条「每周论文占比」曲线，再按周整理成时间线
3. **持续提出洞察**：每次抓取后，七个探测器在全部曲线上重新跑一遍，生成按周归档的洞察卡片

## 运行

```bash
python3 -m tern          # 打开 http://127.0.0.1:8787
```

只用 Python 3.10+ 标准库，不需要安装依赖。首次启动时会在后台回填过去 26 周的数据（每个分类每周抽样 240 篇，并记录 arXiv 给出的真实周投稿量）。arXiv 限速约 3 秒一次请求，回填大约需要 15–20 分钟；累计到 3 个完整周后页面就开始出图。之后每天 07:00 自动抓取全量新论文（从上次抓到的位置接着抓，漏跑的日子会在下次补上，最多补 21 天），也可以点右上角的「立即抓取」。

其他命令：

```bash
python3 -m tern fetch               # 抓取一次并分析，然后退出（可以挂到 cron 上）
python3 -m tern backfill 52 300     # 回填更长的历史：52 周，每类每周 300 篇
python3 -m tern analyze             # 只重新计算
```

环境变量：`TERN_HOST`、`TERN_PORT`、`TERN_DAILY_HOUR`、`TERN_BACKFILL_WEEKS`、`TERN_BACKFILL_PER_WEEK`、`TERN_DATA_DIR`；部署相关见下文的 `TERN_PUBLISH_R2`、`TERN_READONLY`，以及经 Cloudflare 隧道暴露时用的 `TERN_ALLOW_IPS`（逗号分隔的放行 IP）。

### 可选：Claude 周度备忘录

执行 `pip install anthropic`，并设置好 `ANTHROPIC_API_KEY`（或先运行 `ant auth login`）。之后每周第一次分析时，系统会把统计快照交给 `claude-opus-5-5`，写一份研究员备忘录，显示在雷达页顶部。不配置也不影响其他功能。

## 线上只读副本（Cloudflare）

数据只有一个写入方：本地实例负责抓取、分析和编辑，每次任务完成后把数据库的一致副本上传到 R2；线上是同一套代码的只读模式，跑在 Cloudflare Containers 里。

```
本地：抓取 / 分析 / 编辑 → data/tern.db → 一致副本 → R2 tern-data/tern.db
线上：Worker → 发现 R2 有新版本就推给容器 → 容器（TERN_READONLY=1）提供页面
```

- 本地开启发布：`TERN_PUBLISH_R2=tern-data python3 -m tern`。抓取或分析完成后立即发布；在本地新建信号、写判断等修改，最多 10 分钟后发布。上传通过 wrangler 完成，使用本机的 Cloudflare 登录，不保存任何密钥
- 本地常驻：在 macOS 上可以注册成 launchd 用户服务（`RunAtLoad` + `KeepAlive`，环境变量里带上 `TERN_PUBLISH_R2`），开机自启、崩溃自动重启
- 线上部署：`cd deploy/cloudflare && npm install && npx wrangler deploy`（需要本机有 Docker）
- 线上只读：所有修改按钮隐藏，写接口返回 403；Worker 每分钟最多检查一次 R2 版本
- 访问控制：Worker 先按 IP 限流（默认每个 IP 每分钟 120 次，用一个 Durable Object 精确计数，超出返回 429），被拦下的请求不会唤醒容器；`ALLOW_IPS` 可选，留空即公开
- 费用：Workers 付费计划每账号每月最低 5 美元；容器空闲 20 分钟后休眠，休眠期间不计费；数据库副本在 R2 免费额度内

## 页面

| 页面 | 内容 |
|---|---|
| 雷达 | 本周头条洞察、曲线墙（所有信号的占比走势和倍数小图）、本周洞察、新词雷达 |
| 时间线 | 各领域每周投稿量；逐周记录当周跳升的信号、新出现的词、代表论文和当周产生的洞察 |
| 洞察 | 全部洞察卡片，可以按类型筛选，也可以收藏或忽略 |
| 信号 | 单个信号的占比曲线、分领域拆解（图表/表格）、近期与基线对比、相关论文；可以**新建自定义信号**（输入正则时实时预览命中情况，保存后自动回算全部历史） |
| 我的判断 | 写下判断并绑定信号，每次抓取后系统都会用数据重新打分（证据支持 / 证据相反 / 尚无变化） |
| 论文 | 全文检索原始材料，每条曲线都能追溯到具体论文 |

## 洞察探测器

近期窗口（默认 4 周）与之前的基线窗口（默认 12 周）比较；数据较少时，两个窗口会自动缩短。

| 类型 | 规则 |
|---|---|
| 加速 / 回落 | 占比倍数 ≥1.25× 或 ≤0.8×，且双比例 z 检验 \|z\| ≥ 2.5；同时给出按对数斜率估算的翻倍时间 |
| 跨领域同步 | 同一信号在 ≥3 个领域同时上升（各领域都满足 ≥1.25× 且 z ≥ 2），这就是 2016 年 GPU 那种形态 |
| 渗透 | 占比 ≥1% 的领域数量增加 |
| 格局变化 | 在基座模型组内，论文提及占比的排名第一发生更替，或某个模型排名上升 ≥2 位 |
| 新词 | 至少在 2 篇论文标题中出现、近期相对频率 ≥3× 的短语或缩写（如 TTT、GPT-6、masked diffusion） |
| 投稿量 | 某个分类的周投稿量增长 ≥15%（会附注：会议截稿季可能造成短期激增） |
| 整体态势 | ≥3 条曲线同时加速 |
| 我的判断 | 对关联信号变化倍数的几何平均做判定 |

## 局限

- 只匹配标题和摘要的关键词，不读全文。倍数只是线索，要点进论文核对
- 回填的那几周是抽样数据（取每周首尾各一半），最近几周是全量数据。占比对抽样是稳健的，绝对数量则以 arXiv 的官方计数为准
- 时间序列越长越有价值：回填 26 周只是起点，系统每天运行，曲线就会每天变长

## 结构

```
tern/config.py     分类与默认信号定义
tern/arxiv.py      arXiv API 客户端（限速，遇到 429 时退避重试）
tern/ingest.py     每日抓取与抽样回填
tern/analysis.py   时间序列、探测器、时间线（生成单一快照）
tern/jobs.py       后台任务队列与每日调度
tern/memo.py       可选的 Claude 周度备忘录
tern/server.py     JSON API 与静态文件服务（含只读模式）
tern/publish.py    把数据库一致副本发布到 R2
web/               单页前端（原生 JS + 手写 SVG 图表，支持亮色/暗色主题）
data/tern.db       SQLite（已加入 gitignore）
Dockerfile         线上只读容器镜像
deploy/cloudflare/ Worker（限流、同步数据、转发）与 wrangler 配置
```
